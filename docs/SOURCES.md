# Sources

Every public page this pack relies on, with the date its status was checked and the
code it returned. Four rules, because a source list is worth exactly as much as the
discipline behind it:

1. **Exact URLs, never a wildcard or a navigation section.** A `*` in a source list
   is an unbounded corpus, not a citation.
2. **A recorded date and status code**, so a reader can tell a live source from a
   stale one.
3. **Repositories pinned to a commit.** A branch name is not evidence.
4. **Excluded candidates listed with a reason.** Silence is not a decision.

A 200 proves the page exists and is publicly reachable without authentication. It
does not prove any particular statement on it — which is why the documents in this
pack name the mechanism they are describing rather than citing a page and leaving the
reader to find the sentence.

Re-check with `make links-live`. The interval is 90 days; last checked **2026-09-15**.
